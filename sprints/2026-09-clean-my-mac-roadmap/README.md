# Sprint planning - Clean My Mac Local

Objetivo: evoluir o `mac-safe-cleaner` de uma ferramenta funcional para uma experiencia local mais clara, segura e confiavel para limpeza assistida no macOS.

## Principios do produto

- Nunca apagar diretamente durante a varredura.
- Priorizar quarentena reversivel antes de remocao permanente.
- Explicar o motivo de cada sugestao.
- Evitar tocar em areas criticas do sistema.
- Preferir limpeza de artefatos de usuario, caches e diagnosticos antigos.
- Medir impacto e risco antes de ampliar o escopo.

## Foco das proximas sprints

1. Melhorar a experiencia do usuario.
2. Expandir funcionalidades sem aumentar risco operacional.
3. Criar uma politica mais inteligente para logs no macOS.
4. Adicionar telemetria local de execucao, sem enviar dados para fora.
5. Facilitar instalacao e uso diario via app macOS.

## Artefatos desta pasta

- `sprint_backlog.md`: backlog priorizado para proximas sprints.
- `macos_log_cleanup_research.md`: pesquisa tecnica sobre limpeza segura de logs no macOS.
- `ux_improvements.md`: melhorias de interface e experiencia.
- `acceptance_criteria.md`: criterios de aceite por tema.
