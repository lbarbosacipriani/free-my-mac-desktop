# Criterios de aceite - Apple UX redesign

## App desktop

- Ao clicar Run no Xcode, uma janela aparece imediatamente.
- A janela tem sidebar nativa.
- A toolbar usa controles nativos.
- O app mostra estado claro quando o container esta parado.
- O app mostra estado claro quando o Docker esta abrindo.
- O app mostra estado claro quando a API esta pronta.

## Experiencia Apple

- Layout usa sidebar + conteudo, nao dashboard web.
- Acoes frequentes ficam na toolbar.
- Acoes destrutivas nao ficam misturadas com acoes comuns.
- Preferencias ficam em tela propria.
- Textos sao curtos e orientados a acao.
- Icones usam SF Symbols.

## Varredura

- Usuario consegue iniciar varredura pela interface nativa.
- Usuario acompanha tempo decorrido.
- Usuario ve total de candidatos e espaco potencial.
- Erros aparecem com explicacao e caminho para logs.

## Candidatos

- Lista nativa permite selecionar itens.
- Itens podem ser filtrados por categoria e risco.
- Item selecionado mostra detalhe com motivo e risco.
- Botao "Mover para quarentena" mostra resumo antes de executar.

## Quarentena

- Sidebar tem secao Quarentena.
- Usuario consegue ver sessoes antigas.
- Usuario consegue restaurar item.
- Purga permanente exige confirmacao nativa.

## Segurança

- Nada e apagado diretamente pela tela de candidatos.
- Base ativa do Unified Logging nao e sugerida.
- Logs recentes nao entram na selecao padrao.
- A interface diferencia baixo risco de itens que exigem revisao.
